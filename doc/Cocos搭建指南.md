# 谜题星旅 · Cocos Creator 3.8 搭建操作指南

> 本指南对应 `assets/` 下已生成的代码。所有 UI 控件、动画特效均由 TypeScript 代码构建（Graphics + tween），
> **不依赖任何图片资源**，你在编辑器里只需要做一件事：给 GameRoot 挂上入口脚本。

---

## 一、工程结构总览

```
assets/
├─ scenes/
│  └─ main.scene          ← 主场景（Canvas + Camera + GameRoot，已写好）
└─ scripts/
   ├─ Game.ts             ← 唯一入口组件（挂在 GameRoot 上）
   ├─ core/
   │  ├─ Const.ts         ← 设计分辨率 750×1620、糖果调色板
   │  ├─ Data.ts          ← 章节/皮肤/成就/挑战/玩法配置 + 展示用棋盘数据
   │  ├─ Save.ts          ← 存档（sys.localStorage，小游戏自动映射到平台存储）+ 金币事件 + 全局定时器
   │  ├─ Ui.ts            ← UI 控件工厂：圆角面板/糖果按钮/胶囊/进度条/图标按钮 + 动画库（弹入/呼吸/流光/云朵/闪烁/抖动）+ 拖拽滚动
   │  └─ Router.ts        ← 界面栈路由（go/back/replace/resetTo）+ 转场动画 + 切换钩子
   └─ ui/
      ├─ HomeUI.ts        ← 主界面（Logo/吉祥物/开始闯关/三入口/每日倒计时/设置弹窗）
      ├─ ChaptersUI.ts    ← 章节地图（主题横幅切换/蛇形节点路径/星级/锁定/关卡介绍弹窗）
      ├─ ChallengeUI.ts   ← 挑战中心（5 玩法 Tab × 每日/每周/每月，倒计时+记录+奖励）
      ├─ AchvUI.ts        ← 成就（环形总进度 + 8 成就进度条）
      ├─ ShopUI.ts        ← 皮肤商城（6 款皮肤/购买确认/装备/迷你棋盘预览）
      ├─ GameUI.ts        ← 玩法界面（5 种棋盘展示 + 数独选格填数 + 扫雷翻开 + 暂停 + 结算流程）
      ├─ Achievement.ts   ← 成就检查与解锁弹窗（排队，不打断结算）
      ├─ ModalUI.ts       ← 弹窗系统（遮罩+弹入+队列+toast）
      └─ Confetti.ts      ← 彩带粒子（结算/成就庆祝）
```

**玩法逻辑规则按约定暂未实现**：数独可点格选数、扫雷可翻开看数字（无胜负判定），
所有玩法通过「▶ 演示通关结算」按钮验证完整的进入 → 游玩 → 结算 → 存档 → 成就流程。

## 二、首次打开（你需要的操作）

### 步骤 1：用 Cocos Dashboard 打开项目
1. 打开 **Cocos Dashboard** → 项目 → 找到 `mini-game`（若不在列表，点「添加已有项目」选择 `F:\zcode\cocos-mini-game\mini-game`）
2. 用 **3.8.8** 编辑器打开。首次打开会导入资源并生成 meta 文件，等待右下角进度完成（约 1~2 分钟）。

### 步骤 2：打开主场景
- **资源管理器**（底部面板）→ `assets/scenes` → 双击 `main.scene`
- 打开后「层级管理器」应能看到：`Canvas ├─ Camera └─ GameRoot`

### 步骤 3：给 GameRoot 挂入口脚本（唯一手动步骤）
1. 「层级管理器」选中 **GameRoot**
2. 右侧「属性检查器」拉到最底 → 点 **「添加组件」**
3. 选择 **「自定义脚本」→「Game」**（或搜索 `Game`）
4. **Ctrl + S** 保存场景

### 步骤 4：运行预览
- 点编辑器顶部 **▶ 预览按钮**（默认浏览器预览）
- 浏览器里应看到糖果风主界面：金币 500、开始闯关、挑战/成就/商城
- 建议按 F12 切换设备模拟（iPhone/Android 竖屏）检查适配

> ⚠️ 如果 `main.scene` 双击打不开或报错（版本兼容问题），用下面的 **附录 A 手动建场景**，2 分钟搞定。

## 四、构建到微信 / 抖音小游戏

### 通用准备
- 微信小游戏：申请 [微信小游戏 AppID](https://mp.weixin.qq.com)（个人主体可选「游戏」类目需版号，测试期可用**测试号**）
- 抖音小游戏：申请 [抖音开发者 AppID](https://developer.open-douyin.com)
- 下载对应 **开发者工具**（微信开发者工具 / 抖音开发者工具）

### 步骤（编辑器内）
1. 菜单 **项目 → 构建发布**（或顶部「构建发布」面板）
2. 发布设置里点 **＋ 添加场景**，把 `assets/scenes/main.scene` 加入「包含场景」并设为启动场景
3. 平台选择：
   - **微信小游戏**：填 AppID → 构建方向「竖屏」→ 点「构建」
   - **抖音小游戏**（3.8.8 原生支持）：填 AppID → 同样构建
4. 构建完成后点「打开目录」→ 在对应开发者工具里 **导入项目**（选 `build/wechatgame` 或 `build/bytedance-mini-game` 目录）
5. 开发者工具里即可真机预览（扫码）

### 首次构建建议
- 先构建 **Web Mobile** 平台验证（构建后点「预览」），确认无误再上小游戏平台
- 设计分辨率 750×1620 + FIXED_WIDTH 已适配主流全面屏；刘海屏安全区正式版再加 `screen.safeArea` 适配

## 五、常见问题

**Q：预览黑屏 / 控制台报 `Cannot read ... of null`？**
先看是否漏了步骤 3（GameRoot 没挂 Game 脚本）。层级管理器里 GameRoot 的属性面板应有 `Game` 组件。

**Q：中文/emoji 显示方块？**
系统字体问题。Windows 正常；个别安卓真机 emoji 渲染不全 → 正式版把图标换成图集资源（预留了 `Ui.emoji` 单一出口，届时只改这一个函数）。

**Q：改了脚本没生效？**
编辑器里 Ctrl+R 重新加载；或预览页面刷新（浏览器预览会自动热重载）。

**Q：想重置存档重测？**
设置弹窗里点「重置存档」，或浏览器 F12 → LocalStorage → 删除 `puzzlestar_v1`。

## 附录 A：手动建场景（main.scene 打不开时的 fallback）

1. 资源管理器 `assets/scenes` 右键 → **新建 → Scene**，命名 `main`，双击打开
2. 编辑器默认生成 `Canvas`（含 `Camera`）——无需改动
3. 选中 `Canvas` → 右键 → **创建 → 2D 对象 → Node**，命名 `GameRoot`
4. 选中 `GameRoot` → 属性检查器 → **添加组件 → 自定义脚本 → Game**
5. Ctrl+S 保存 → ▶ 预览

（代码会自动把 GameRoot 拉伸到全屏并设置设计分辨率，无需手动配 Widget。）
