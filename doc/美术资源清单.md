## 〇、给 AI 的统一风格前缀（每条提示词开头都带上）

**中文**：3D 卡通休闲手游 UI 素材，糖果色，厚实圆角描边，软胶/果冻质感，顶部高光，柔和阴影，Q 版可爱，明亮饱和

**英文（效果更稳）**：
> 3D cartoon casual mobile game UI asset, candy color palette, thick rounded outline, soft glossy plastic / jelly texture, top highlight, soft shadow, cute chibi style, vibrant saturated colors, isolated on transparent background, PNG

**通用规格**：透明背景 PNG；图标类出图 ≥ 256×256（导入后缩放）；同系列一次生成保持同风格（同 prompt 连续生成或垫图）。

## 六、接入方式（资源到位后怎么换）

- **图标类**：统一替换 `core/Ui.ts` 的 `Ui.emoji()` 为 Sprite 加载（该函数是唯一出口，一次改动全游戏生效）；挑战 Tab / 成就 / 挑战卡的图标走 `Data.ts` 配置里的 icon 字段换成图片资源路径
- **九宫格**：`Ui.panel / candyBtn / pill` 内部把 Graphics 绘制换成 SpriteFrame（modifiedBorder：上下左右各 12~16px），对外接口不变，界面零改动
- **背景**：`Ui.background()` 换成全屏 Sprite；章节背景在 `Data.ts` 的 CHAPTERS 里加图片路径字段
- **吉祥物**：`HomeUI.ts` 吉祥物节点替换；结算/引导复用
- **音效**：新增 `core/AudioMgr.ts`（play/check 开关已在设置弹窗预留）
