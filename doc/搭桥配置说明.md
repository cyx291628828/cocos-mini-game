# 搭桥（Hashi）配置表字段说明

> 文件位置：`assets/resources/config/hashi.json`
> 加载方式：游戏启动时由 `core/Config.ts` 通过 resources 自动加载，按 `id` 索引
> 生效方式：关卡表（level.json）里把某一关指向某个 id，进入该关即读取该行数据

---

## 一、玩法规则回顾

- 棋盘为 N×N 方格网，岛（标有数字）放在**格线的交叉点**上，数字 = 该岛拥有的桥数
- 玩家在岛与岛之间搭桥：沿格线直线连接、方向只能是横向/纵向、桥不能交叉、不能跨过其它岛
- 两座岛之间最多 2 座桥（双桥画成双线）
- 每座岛的桥数必须恰好等于岛上数字，且所有岛连成一片即通关
- **每关出题带唯一解验证**（多解的题面不会出现）
- **无失败路径**：搭错桥无任何惩罚、不会自动删除，可用「检测」按钮自查；星级只看用时

## 二、操作方式（三种）

1. **点岛**：点一座岛选中，再点同一行/列的另一座岛搭桥；重复点同一对：1 座 → 双桥 → 拆除
2. **点空白格线**：点两岛之间的空白区域，自动找就近的两条格线搭桥（最近线两端没有一对岛时自动试次近线，都不行则点击无效）
3. **按住岛滑动**：按住一座岛朝上下左右甩动（与轴向夹角 ±30° 内），松手后向该方向最近的岛搭桥

## 三、字段一览

| 字段 | 类型 | 可填值 | 说明 |
|---|---|---|---|
| `id` | string | 自定义唯一标识，建议 `hashi_<难度>` | 配置行唯一 id，关卡表通过它引用本行 |
| `board` | number | 建议 `7` / `9` / `11`（奇数） | 棋盘边长：board × board 格 |
| `islandMin` | number | ≥ 5 | 岛数下限（出题随机取 islandMin~islandMax 之间的目标岛数，实际可能略少） |
| `islandMax` | number | ≤ board × board / 4 | 岛数上限；岛越多约束越多、题面越难 |
| `difficulty` | string | `简单` / `普通` / `困难` | 难度名，用于界面展示 |
| `timeCostStar` | number[] | 秒数数组，升序 | **超时扣星阶梯**：用时每达到一个阈值扣 1 颗星 |
| `rewardCoins` | number | 正整数 | 通关金币奖励 |
| `keyHint` | boolean | `true` / `false` | 是否显示「💡提示」按钮（提示会高亮一座未搭的解中桥） |

## 四、星级与结算

- 胜利条件：每岛桥数与数字一致 **且** 全岛连通（搭错桥会卡住度数，需自行拆除改正）
- 剩余星 = 3 − 超时达到的阈值个数（最低 0）；金币按 `rewardCoins` 发放
- 「🔍 检测」按钮：已搭的桥全部是解中桥 → 提示「目前为止全都对」；存在解外桥 → 提示「当前有错误」

## 五、难度机制（难度 = 推理深度）

出题器内置**分级逻辑求解器**，按解题的级联波数与是否需要试错来分带（参照 erthium/hashiwokakero 的「规则步数 + 试错步数」思想）：

| 难度 | 推理深度 | 说明 |
|---|---|---|
| 简单 (L1) | 1 波 | 每个数字一眼可读（含高阶解法：数字=最多桥数全双桥 / 比最多桥数少 1 → 每边至少 1） |
| 普通 (L2) | ≥2 波 | 一眼看不出来，需要多步链式推理（前一步的桥解锁下一步的判断） |
| 困难 (L3) | 需要试错 | 必须使用假设-排除-矛盾（假设某边不搭 → 导出矛盾 → 证明必须搭） |

所有难度都保证唯一解。`board` 和 `islandMin/islandMax` 影响同一难度带内的题面规模与岛数。

## 六、难度参考

| id | 棋盘 | 岛数 | 推理深度 | 提示 |
|---|---|---|---|---|
| hashi_easy | 7×7 | 7~10 | L1 一眼题 | 有 |
| hashi_normal | 9×9 | 11~15 | L2 多步推理 | 有 |
| hashi_hard | 11×11 | 14~18 | L3 假设矛盾 | 无 |

## 六、第六章关卡配置（level.json）

第六章（chapter: 5）12 关全为搭桥，难度递进：easy×4 → normal×4 → hard×4：

```json
{ "id": "L5-0", "chapter": 5, "level": 0, "game": "hashi", "cfgId": "hashi_easy" },
...
{ "id": "L5-11", "chapter": 5, "level": 11, "game": "hashi", "cfgId": "hashi_hard" }
```
